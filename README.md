## ✨ Key Features & Technical Highlights

* **Dynamic Theme Switcher:** Custom VBA automation allowing users to instantly toggle the entire UI (background containers, KPI cards, text labels, and charts) between a high-contrast Dark Mode and a crisp Light Mode.
* **Executive KPI Suite:** Real-time visibility into Total Sales, Average Weekly Sales, Holiday Revenue, Holiday Share %, Total Markdowns, and Active Store metrics.
* **Interactive Slicers:** Global slicers mapped across multiple Pivot Tables for Year, Store, and Holiday status (`True`/`False`), updating all metrics dynamically.
* **Advanced Error Guardrails:** Integrated `IFERROR` implementation preventing broken `#REF!` errors or blanks during heavy filtering, ensuring clean text fallbacks.
* **High-Density Data Engineering:** Optimized structure built to aggregate and analyze massive retail datasets smoothly.

---

## 🛠️ Tech Stack & Architecture

* **Microsoft Excel:** Data modeling, Pivot Tables, Pivot Charts, Slicers, and Conditional Formatting.
* **VBA (Visual Basic for Applications):** UI automation, custom theme switching logic, and event management.
* **UI/UX Design:** Modern card-based container layout with structured visual hierarchy tailored for C-suite presentations.
